# ΒΕΛΤΙΣΤΟΠΟΙΗΣΗ
Το μάθημα «Βελτιστοποίηση» εισάγει τους φοιτητές στις βασικές έννοιες, τις μαθηματικές μεθόδους και τις υπολογιστικές τεχνικές που χρησιμοποιούνται για την επίλυση προβλημάτων βελτιστοποίησης. Παρουσιάζονται μέθοδοι για προβλήματα χωρίς και με περιορισμούς, τεχνικές αναζήτησης και αριθμητικές μέθοδοι, καθώς και σύγχρονες ευρετικές και μεταευρετικές προσεγγίσεις, όπως οι εξελικτικοί αλγόριθμοι. Ιδιαίτερη έμφαση δίνεται στην πρακτική υλοποίηση των αλγορίθμων και στην εφαρμογή τους σε πραγματικά προβλήματα, ώστε οι φοιτητές να αποκτήσουν την ικανότητα να διατυπώνουν ένα πρόβλημα βελτιστοποίησης, να επιλέγουν την κατάλληλη μέθοδο επίλυσης και να αξιολογούν την ποιότητα των αποτελεσμάτων.
