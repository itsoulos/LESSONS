# ΥΠΟΛΟΓΙΣΤΙΚΗ ΝΟΗΜΟΣΥΝΗ
Το μάθημα «Υπολογιστική Νοημοσύνη» εισάγει τους φοιτητές στις βασικές έννοιες, τις μεθόδους και τους αλγορίθμους που χρησιμοποιούνται για την ανάπτυξη ευφυών υπολογιστικών συστημάτων. Παρουσιάζονται τεχνικές όπως τα τεχνητά νευρωνικά δίκτυα, οι εξελικτικοί και γενετικοί αλγόριθμοι,  άλλες μέθοδοι μηχανικής μάθησης και υπολογιστικής νοημοσύνης. Ιδιαίτερη έμφαση δίνεται στην πρακτική υλοποίηση και εφαρμογή των μεθόδων σε προβλήματα ταξινόμησης, πρόβλεψης, προσέγγισης συναρτήσεων και λήψης αποφάσεων. Στόχος του μαθήματος είναι οι φοιτητές να κατανοήσουν τις βασικές αρχές των τεχνικών υπολογιστικής νοημοσύνης και να αποκτήσουν την ικανότητα να επιλέγουν, να υλοποιούν και να αξιολογούν κατάλληλες μεθόδους για την επίλυση σύνθετων πραγματικών προβλημάτων.
